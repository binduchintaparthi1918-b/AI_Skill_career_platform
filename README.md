# 🎓 CareerAI – AI-Powered Skill & Career Platform

CareerAI is an AI-powered career guidance platform designed to help users understand their skills, identify skill gaps, and explore suitable career opportunities.

## 🚀 Live Demo

👉 **[Open CareerAI Live App](https://aiskillcareerplatform-czx2uwo37y4vhxtp9x47ld.streamlit.app)**

## 💻 GitHub Repository

👉 **[View Source Code](https://github.com/binduchintaparthi1918-b/AI_Skill_career_platform)**

---

## ✨ Features

* 📝 **Skill Assessment** – Evaluate skills through an interactive assessment.
* 📊 **Skill Gap Analysis** – Identify skills and areas that need improvement.
* 🎯 **Career Recommendations** – Get career suggestions based on skills and assessment results.
* 🤖 **AI-Powered Guidance** – Receive personalized career and learning guidance.
* 📚 **Learning Recommendations** – Get guidance on areas to improve and learn.
* 📈 **Skill Review** – Review assessment results and understand current skill levels.
* 🎨 **Professional UI** – Clean, modern, and user-friendly Streamlit interface.
* 💾 **Database Support** – Stores application data using SQLite.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/binduchintaparthi1918-b/AI_Skill_career_platform.git
```

### 2. Open the Project Folder

```bash
cd AI_Skill_career_platform
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install Required Packages

```bash
pip install -r requirements.txt
```

---

## 🔐 Environment Variables

Create a `.env` file in the project directory.

Add your Groq API key:

```text
GROQ_API_KEY=your_api_key_here
```

⚠️ **Important:** Never upload your `.env` file or API keys to GitHub.

---

## ▶️ Run the Application Locally

Start the Streamlit application using:

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## 🎯 Purpose of the Project

The main goal of CareerAI is to provide users with an easy-to-use platform for understanding their skills and discovering suitable career paths.
